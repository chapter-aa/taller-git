# taller-git

Repositorio de práctica del programa MLOps del chapter: aquí cada persona hace su primer pull request.

## Cómo se trabaja aquí

1. Crea una rama desde `main` con el nombre `tu-usuario/tema`.
2. Haz tus cambios y commits, y envíalos con push.
3. Abre un pull request hacia `main`.
4. Otra persona lo revisa y lo aprueba.
5. Fusiona y borra la rama.

`main` está protegida: ningún cambio entra sin pull request y sin una aprobación.

## Regla de oro

Este repositorio es **público**. Nunca subas datos, contraseñas, tokens ni nada relacionado con tu trabajo:
ni código, ni nombres de tablas o modelos, ni nombres de empresas.
